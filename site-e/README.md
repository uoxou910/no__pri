# サイトE — フレカ置き場E

サイトCのUI・機能・GAS認証方式を複製した独立サイトです。マイキャラは **そると / みりん / すう** の3人です。

- 公開画面（初期設定前は準備中）: https://uoxou910.github.io/no__pri/site-e/
- 管理画面（GAS接続後に使用可能）: https://uoxou910.github.io/no__pri/site-e/edit.html
- 保存先（新規・0件）: https://docs.google.com/spreadsheets/d/1hTNcgDR9k0bq8XBjFeERsyUipnyJ12jb1k6vbU6De9s/edit
- 画像フォルダ（新規）: https://drive.google.com/drive/folders/1n663feKRACZhnyl-jDrx7Fwss4D31ZXb
- 専用GASコード: gas/site-e-backend.gs

## 引き継ぐ機能
公開カード一覧、キャラごとの切替、文字検索、画像拡大、画像サムネイルキャッシュ、無限スクロール、管理者パスワード認証、カード追加・編集・画像差し替え・削除・表示/非表示・一括削除、キャラ別の単色/グラデーション設定。

サイトCのカード80件と旧データは**コピーしていません**。サイトEは0件スタートで、最初のカラーのみ初期値を用意しています。

## 仕上げ（GAS公開）
1. https://script.google.com/home で**新しい**Apps Scriptプロジェクト「サイトE」を作ります。サイトCのGASを編集しないでください。
2. `gas/site-e-backend.gs` を全文 `コード.gs` に貼り付けます。
3. 「プロジェクトの設定」→「スクリプト プロパティ」に `ADMIN_PASSWORD` を追加し、独立した管理パスワード（4文字以上）を設定します。**パスワードをGitHubに書かないでください。**
4. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」、実行するユーザーは自分、アクセスできるユーザーは全員、でデプロイします。
5. 新しい `/exec` URLを `site-e/assets/config.js` の `gasUrl` に設定します（サイトCのURLは絶対に使用しない）。
6. 公開画面と管理画面で、空の一覧・ログイン・新規カード追加・カラー保存をテストします。

GAS内には新しく作成したデータシートと画像フォルダのIDを埋め込み済みです。`SPREADSHEET_ID` と `IMAGE_FOLDER_ID` を改めて設定する必要はありません。

## 認証
サイトCと同じ方式で、**公開画面の閲覧はPIN不要、管理画面のみGAS側で管理パスワードを照合**します。管理者トークンは1時間有効です。

## 配置
GitHub連携から新規リポジトリを作成する操作が利用できなかったため、サイトCのリポジトリ内の `site-e/` に配置しています。ソースとローカルキャッシュ・GAS・スプレッドシート・画像保存先は分離しています。将来別リポジトリへコピーすることも可能です。
