## サイトC（サイトDと共通の画面構成）

- 公開: https://uoxou910.github.io/no__pri/
- 管理: https://uoxou910.github.io/no__pri/edit.html
- キャラクター: のあ、ふあ、るる、るり
- 公開画面: サイトDと同じカードレイアウト・キャラ別検索・無限スクロール・画像拡大
- 管理画面: フレカ追加・編集・公開／非公開・削除・一括削除、PC 6列表示、キャラ名が黒字／コーデ名がグレー
- 認証: このサイトC専用のタブ内セッション情報を利用。ページ更新や公開画面への往復時も自動で再認証し、ログアウト時に情報を破棄
- 所持コーデ・印刷予定は画面に表示しない

**フレカのデータは元のサイトC用GAS・Google Driveに保存します。** GAS接続先は既存の `assets/config.js` をそのまま使用し、データ移行や既存レコードの一括上書きは行いません。アップロードは元の `upload` と `update` のAPIを利用するため、サイトDの一括保存処理は使用しません。

**カラー設定は現時点ではブラウザ内の保存です。** サイトC用GASにはサイトDのカラー設定保存APIがないため、別端末・別ブラウザには同期されません。全端末共通の配色にするには、サイトC用GASへの色設定保存APIの追加が必要です。

画像を既存フレカへ差し替えるAPIもサイトCにはないため、既存フレカ編集ではキャラ名とコーデ名を変更できます。公開／非公開の状態はそのまま維持します。
